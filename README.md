# MGAide iOS

MGAide iOS 的公开安装包与更新说明。本仓库用于版本分发。

[下载最新正式版](https://github.com/qwasd7680/MGAide_iOS_Releases/releases/latest)

## 安装

- 支持 iOS / iPadOS 17 或更新版本。
- 下载 Release 附件中的 `-unsigned.ipa`，自行签名后安装。另附 SHA-256 校验文件与 `-signing.zip` 自签资料。
- 签名时保留 iMessage 贴图和直播小组件扩展，并参照自签资料配置所需权限。小组件共享配置依赖 App Group，刷新由 iOS 调度。
- GitHub 自动提供的 Source code ZIP/TAR 仅包含发布说明，安装应用请使用 IPA 附件。

## 版本

首个正式版为 **8.5.001（80532）**，与发布时 Android 版本同步。

[阅读首版说明](releases/v8.5.001.md)

安装后可在「设置 → 检查更新」查看最新正式版、更新说明和 IPA 下载入口。
